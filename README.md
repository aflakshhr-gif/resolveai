# ResolveAI
Private customer-support workspace with responsive web dashboard, installable PWA, public product website, QR access and Expo mobile app.
## Addresses
- Private sign-in: https://resolveai.aflakshhr.workers.dev/login/
- Public website: https://resolveai.aflakshhr.workers.dev/website/
- QR access: https://resolveai.aflakshhr.workers.dev/qr/
The private app uses the dedicated `resolveai-db` database. Initial owner setup uses the `RESOLVEAI_SETUP_TOKEN` Worker secret. Public registration is disabled.
The app in `mobile/` signs in against the same Worker API, stores its mobile session with Expo SecureStore and reads the shared workspace. Native APK/IPA builds and store submissions require Expo/EAS and signing credentials; they are not generated by web deployment.
Current limits: replies are saved internally and not sent to customers; external integrations, password recovery, verified email, push notifications and production security review remain outstanding. Copilot is rule-based demo logic, not a real LLM. Never commit API keys or setup secrets. Never use Block 17's Worker or database.
